# dsh-antigravity-oauth

Isolated Gemini Cloud Code Assist login for DeepSeek Harness.

The plugin owns `.dsh-antigravity-oauth.json` next to DSH home. It never reads or writes official CLI auth files. The harness route is `agy-google-antigravity`. Public models are `gemini-3.7-flash` and `gemini-3.5-flash`. Search is on by default. Google image generation is off.

Sign in from Settings. Review Google Terms of Service before connecting.
